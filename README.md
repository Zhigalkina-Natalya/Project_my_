# Виджет банковских операций

## Описание

```
Учебный проект на Python, разработанный в рамках курса Skypto "Профессия Python-разработчик". 
Виджет имеет возможность отображать операции клиента.
```

## Установка

1. Клонируйте репозиторий:

```
git clone https://github.com/Zhigalkina-Natalya/Project_my_
```

2. Установите зависимости:

```
Используйте инструмент Poetry.
Запустите команду poetry install в терминале, находясь в корневом каталоге вашего проекта.
```

## Содержание файлов:

 Название файла | Содержание файла
